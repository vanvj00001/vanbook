《孟子》通读：跟国君吵架的圣人，如何用辩论救苍生？

前言

战国时期，诸侯征战，生灵涂炭。有一个叫孟轲的老头，周游列国，逢人就讲"仁政"，逢国君就辩论，而且每次都把国君说得哑口无言。他是"亚圣"——儒家道统中仅次于孔子的第二号人物。但跟孔子不一样的是，他不是四处碰壁的"丧家之犬"，他是一个敢于直接跟梁惠王、齐宣王吵架的辩论高手。

他凭什么这么有底气？因为他相信人性本善——人天生就有善良的种子，任何人只要肯"求其放心"，都能成为君子。他还有一件秘密武器，叫做"浩然之气"——一种由正义积累而成的精神力量，充塞于天地之间，凛然不可侵犯。今天的通读篇，我们就把这个跟国君吵架的老头的故事，好好聊一聊。

关键词：孟子、孟子其人、性善论、浩然之气、仁政、梁惠王、齐宣王、民贵君轻、告子

一、亚圣其人：从孤儿到国师

1.1 幼年丧父的"孟母三迁"

孟子的出身比孔子好不了多少。他姓孟名轲，战国时期邹国人（今山东邹城）。他出生的时候，父亲孟激已经去世，只剩下母亲仉氏一个人拉扯他。孤儿寡母，相依为命，这个开局跟孔子惊人地相似。

孟母仉氏是中国历史上最著名的母亲之一，“孟母三迁"的故事几乎每个中国人都知道。最初，他们住在墓地旁边，小孟子就跟别的小孩一起学着哭丧、跪拜。孟母觉得不行，搬到了集市旁边；小孟子又开始学商人讨价还价、吆喝叫卖。孟母又觉得不行，最后搬到了学校旁边；这一次，小孟子开始学习鞠躬行礼、读书写字，孟母这才满意地说：“真吾居矣。“这个故事的真假很难考证，但它反映的观念是真实的：环境对人的影响是决定性的。

还有一个"孟母断机"的故事：有一天，孟子逃学回家，孟母正在织布，她拿起剪刀把织好的布剪断，说：“子之废学，若吾断斯织也。“你荒废学业，就像我剪断这匹布一样。孟子从此勤学，再不敢懈怠。这些故事当然有后世儒家美化的成分，但它们揭示了一个事实：孟子的成功，母亲的教育功不可没。

1.2 拜师子思之门：儒家道统的传递

孟子的老师是谁？司马迁在《史记》中说孟子"受业于子思之门人”，也就是说他不是直接师从子思，而是子思的学生。但无论是子思还是子思的门人，有一点是确定的：孟子继承了孔子的学说，并且将它发扬光大。

子思是孔子的孙子，相传《中庸》就是他写的。如果这个说法属实，那么孟子的师承就直接接续到了孔子本人——他是孔子学说的嫡系传人。但孟子的伟大之处在于，他没有只是简单地继承，而是在继承的基础上做出了重大的理论创新：他把孔子关于"仁"的思想，发展成为完整的"性善论"和"浩然之气"学说，使儒家思想变得更加系统、更加有说服力。

1.3 春风得意的稷下学宫与晚年讲学

孟子生活的时代，诸侯国之间竞争激烈，养士之风盛行。齐国的稷下学宫是当时最大的学术中心，各国学者纷纷前往，议论政务、辩论学说。孟子晚年曾经在稷下学宫讲学，“后车数十乘，从者数百人”，排场之大，一时无两。他在那里广收弟子、传播学说，形成了儒家"思孟学派"的核心阵营。

但孟子并不是一个纯粹的学者。他有强烈的政治抱负——他要用儒家的仁政思想说服诸侯王，改变战国的乱局。他周游列国，尤其与梁惠王、齐宣王来往密切，向他们阐述仁政的理想，批评他们的穷兵黩武。他的论辩风格犀利、直接、不留情面，经常让国君下不来台。这种风格，是他跟孔子最大的不同：孔子温良恭俭让，孟子则是"说大人则藐之”，跟大人物说话，先把对方看轻。

二、最精彩的五场辩论

2.1 见梁惠王：“何必曰利”

《孟子》开篇就是一场火药味十足的辩论。梁惠王见孟子，开口就问：“叟！不远千里而来，亦将有以利吾国乎？“老先生，你不远千里而来，对我的国家有什么好处吗？

孟子毫不客气地回答：“王何必曰利？亦有仁义而已矣。“大王为什么非要谈利益呢？只要讲仁义就够了。然后他分析道：如果国君只想着"何以利吾国”，大夫只想着"何以利吾家”，普通百姓只想着"何以利吾身”，上上下下都只讲利益，那国家就危险了。相反，如果国君讲仁义，大夫讲仁义，老百姓讲仁义，那国家就能稳固。

这段话之所以重要，是因为它奠定了儒家处理利益与道德关系的基本立场：利益不是不重要，但利益必须服从于道德。如果把利益放在第一位，人就会为了利益不择手段；如果把仁义放在第一位，利益反而会随之而来。这个逻辑，在今天看来依然是有效的：奶粉企业只想着赚钱不顾质量，最终会失去市场；企业讲信誉、重质量，反而能获得长期利益。

2.2 齐宣王"以羊易牛”：看见不忍之心

齐宣王是孟子最重要的对话者之一。《孟子》记载了齐宣王很多次与孟子的对话，其中最有意思的是"以羊易牛"的故事。

齐宣王有一天坐在朝堂上，有人牵着一头牛从堂下经过。齐宣王问：把牛牵到哪里去？那人说：用来祭钟。齐宣王说：放了它吧，我看它瑟瑟发抖的样子，像是没有罪过却被送往死地，我实在不忍心。那人问：那么就废除祭钟这个仪式吗？齐宣王说：怎么能废除呢？用只羊来代替吧。

这件事被孟子知道了。孟子见齐宣王时，主动提起这件事，说：“臣闻之胡龁曰，王坐于堂上，有牵牛而过堂下者，王见之，曰：‘牛何之？‘对曰：‘将以衅钟。‘王曰：‘舍之！吾不忍其觳觫，若无罪而就死地。‘对曰：‘然则废衅钟与？‘曰：‘何可废也？以羊易之。’“这就是齐宣王的"不忍之心”——他看到牛的恐惧，产生了怜悯，所以用羊代替。但羊和牛一样是无辜的呀——齐宣王意识到这一点时，自己也觉得荒唐，说"吾何爱一牛？即不忍其觳觫，若无罪而就死地，是以羊易也”。

孟子抓住了这个点，说：“无伤也，是乃仁术也，见牛未见羊也。“没有关系的，这就是仁爱的表现啊——您看到了牛，却没有看到羊。如果您连羊都看到了，您也会怜悯它的。齐宣王说：对啊，听到这个话，百姓都以为我是吝啬。他们为什么会这么想呢？孟子说：这是自然的——您用贵的羊换便宜的牛，百姓当然会觉得奇怪。但您不用感到惭愧，因为"君子之于禽兽也，见其生，不忍见其死；闻其声，不忍食其肉”。君子看到动物活着，不忍心看它们死；听到它们的声音，不忍心吃它们的肉。这是仁心的自然流露。

这段对话的精彩之处在于：孟子没有批评齐宣王伪善，而是把他的"不忍之心"归结为仁爱的萌芽。他告诉齐宣王：你有这个心，你只需要把它推广到政治上就行了。这就是孟子的"推恩"思想——把自己内心的善良推而广之，就是仁政的起点。

2.3 庄暴见孟子：与民同乐才能王天下

庄暴是齐国的大臣，他来见孟子，说：大王真是不行啊——我每次去见他，他都在听音乐，什么好音乐都听。孟子说：这个好办，我去见大王，劝他跟百姓一起娱乐。

孟子见到齐宣王，问：听说大王喜欢音乐，有这回事吗？齐宣王不好意思地说：寡人非能好先王之乐也，直好世俗之乐耳。我不是喜欢古代圣王的音乐，只是喜欢现在流行的通俗音乐。孟子没有追究这个问题，而是顺着说：喜欢流行音乐也没什么问题，关键是谁在听。如果您听音乐的时候，百姓都在发愁，说"我们的君王这么喜欢音乐，我们可怎么办啊”——那您的音乐就不是真正的快乐。如果您听音乐的时候，百姓都很高兴，说"我们的君王精神很好，身体健康，没有什么烦恼”——那您就真正懂得音乐了。

然后孟子说出了那句千古名言：“古之人与民偕乐，故能乐也。“古代的圣王因为能与民同乐，所以才能真正快乐。而"今之王与民同乐，则王矣”——现在的大王如果能与民同乐，就能成就王业了。齐宣王问：怎样才能做到与民同乐呢？孟子说：“无恒产而有恒心者，惟士为能。若民，则无恒产，因无恒心。“没有固定的财产但有坚定的道德信念，只有士能做到。至于普通百姓，如果没有固定的产业，就会失去道德信念，进而铤而走险。

这段话揭示了孟子仁政思想的经济基础：他不是空谈道德，而是认识到道德需要物质保障。如果百姓吃不饱、穿不暖，跟他们谈仁义道德是没有用的。所以仁政的第一步是"制民之产”——让百姓有固定的财产，有房子住，有地种，有余粮。这样他们才会"乐岁终身饱，凶年免于死亡”，然后才谈得上接受道德教育。

2.4 滕文公问政：“世臣"与"巨室”

滕文公是滕国的国君，滕国是一个小国，夹在齐国和楚国之间，随时有被吞并的危险。滕文公向孟子请教如何自保，孟子给他出了主意。

滕文公问：滕国是个小国，夹在两个大国之间。我应该服从齐国呢，还是楚国？孟子说：这个问题我也没法回答。但我可以告诉你一个原则：“世臣"和"巨室"很重要。所谓"世臣”，就是世代为官、忠于国君的老臣；所谓"巨室”，就是有几代传承的大家族。滕文公如果能好好对待这些"世臣"和"巨室”，就能保住自己的国家。

孟子的逻辑是：小国在大国之间生存，最可靠的力量是国内的政治精英集团。如果这些人都忠于国君，愿意为国君效力，滕文公就有了稳定的统治基础。相反，如果国君疏远他们，他们就会离心离德，国家就危险了。这种现实主义的政治智慧，跟孔子"近者悦，远者来"的用人思想是一脉相承的。

2.5 齐人伐燕：该不该干涉他国内政

齐宣王五年（前315年），燕国发生了内乱。齐国趁机伐燕，十日之内攻下燕国都城。齐宣王很得意，问孟子：先生你觉得我这次做得怎么样？

孟子没有直接回答，而是反问：您觉得攻下燕国之后，齐国有能力治理它吗？齐宣王说：不能。孟子说：那就对了。“取之而燕民悦，则取之；取之而燕民不悦，则勿取。“如果燕国百姓欢迎齐国，就取之；如果燕国百姓不欢迎，就不要取。现在齐国伐燕，燕国百姓箪食壶浆以迎王师，但齐国在那里烧杀抢掠，燕国百姓后悔不迭。这样的占领是不能长久的。

果然，后来燕国人民反抗，齐国被迫撤军。孟子的预言应验了。这段对话展示了孟子的一个重要观点：战争和征服如果不是为了人民的利益，就不会有好结果。“得道多助，失道寡助”——仁政不只是道德要求，也是实际的政治需要。

三、性善论：孟子最核心的哲学

3.1 “人性之善也，犹水之就下也”

孟子的性善论是他思想的核心。他说：“水信无分于东西，无分于上下乎？人性之善也，犹水之就下也。人无有不善，水无有不下。“水自然就往下流，人自然就向善。这不是后天教育的结果，而是人先天的本性。

告子不同意这个观点，提出了几个反驳。他说：“性犹湍水也，决诸东方则东流，决诸西方则西流。人性之无分于善不善也，犹水之无分于东西也。“人性就像湍急的水，往东决堤就往东流，往西决堤就往西流，人性不分善恶，就像水分不分东西一样。

孟子反驳说：水确实往下流，但你不能说水没有"上"的倾向——如果你把水撩起来，它也会往上飞；如果你在下面放一块石头，水也会往上溅。所以，人性向善是必然的，但"不善"就像水往上溅一样，是外力作用的结果，不是水的本性。

3.2 四端：恻隐、羞恶、辞让、是非

孟子性善论的细节，集中体现在他对"四端"的阐述中。他说：“恻隐之心，人皆有之；羞恶之心，人皆有之；恭敬之心，人皆有之；是非之心，人皆有之。恻隐之心，仁也；羞恶之心，义也；恭敬之心，礼也；是非之心，智也。”

这段话的意思是：每个人都有同情心，每个人都有羞耻心，每个人都有恭敬心，每个人都有是非心。这四种心就是四种美德的起点：同情心是仁的起点，羞耻心是义的起点，恭敬心是礼的起点，是非心是智的起点。

孟子继续论证：“仁义礼智，非由外铄我也，我固有之也，弗思耳矣。“仁义礼智不是从外面灌输进来的，是我本来就有的，只是没有思考罢了。所以"求则得之，舍则失之”——去追求就能得到，放弃了就会失去。修养的过程，就是"求其放心”——把放逸的心找回来，把丢失的善性找回来。

3.3 良知良能：人天生知道什么是对

孟子提出了"良知良能"的概念：“人之所不学而能者，其良能也；所不虑而知者，其良知也。“不用学习就会的能力叫良能，不用思考就知道的知识叫良知。每个人生来就有良知良能，所以每个人都知道什么是对、什么是错。

举个例子：看到一个小孩快要掉进井里，任何人都会产生惊恐和同情——不是因为跟孩子的父母有交情，不是因为想获得别人的称赞，只是因为这是人性的自然反应。这个"不忍人之心”，就是良知良能的具体体现。

这种观点在今天仍然有重要意义：道德不是外部强加的规则，而是人内心本来就有的东西。教育的目的不是灌输道德，而是启发人发现自己本有的善性。这是儒家教育和西方宗教教育最根本的区别：西方的宗教道德是神给的，儒家的仁义道德是人自己的。

3.4 为什么有人会变坏：放其良心

既然人性本善，为什么还有那么多人作恶？孟子的回答是：不是他们的本性坏了，而是他们的"良心"被遮蔽了。他说：“富岁，子弟多赖；凶岁，子弟多暴，非天之降才尔殊也，其所以陷溺其心者然也。“丰收的年代，年轻人多数懒惰；灾荒的年代，年轻人多数暴虐，这不是因为他们的资质不同，而是因为环境影响了他们的心。

所以修养的第一步是"求其放心”——把放逸的心找回来。很多人的心被名利、欲望、习俗所蒙蔽，就像镜子蒙上了灰尘，失去了本来的清明。修养的过程，就是擦拭镜子的过程，让它重新能够照见万物。

四、浩然之气：最中国的人格力量

4.1 “我善养吾浩然之气”

“浩然之气"是孟子最独特的概念，也是中国思想史上最富感染力的表述之一。公孙丑问孟子：您有什么特长？孟子说：我善于培养我的浩然之气。

公孙丑问：什么是浩然之气？孟子说：这就很难说了。它是一种精神力量，充满了天地之间，既广大又刚强。用直道行事它就正直饱满，用弯道行事它就弯曲饱满。它日积月累地生长，放置不用就会消亡。它配合义和道而存在，如果不配合义和道，就会枯萎。

“浩然之气"不是一般意义上的勇气或者豪气。它是一种由长期正义行为积累而成的精神力量，是一个人道德修养达到一定程度之后的自然产物。它不是一时的激动，而是持久的、稳定的、不可动摇的精神状态。一个有浩然之气的人，在任何情况下都不会做违背良心的事，因为他内心的力量足以抵御任何外在的压力。

4.2 浩然之气的养成：集义而生

浩然之气是怎么养成的？孟子的回答是：不是一次两次的正义行为就能养成，而是要长期积累，“集义而生”。

孟子讲了一个故事：有一个宋人，整天站在田野里，望着远处说：我家祖上的规矩是——要帮忙推车，但不能超过三天，超过三天就超过规矩了，所以我不推。宋人想用"三天"来限制自己的善行，这不是真正的善——因为他做善事是为了符合一个外在的规矩，而不是发自内心的自然要求。

真正的浩然之气，必须建立在"义"的基础上。“义"是"应该做的事”，不是"能得到什么好处的事”。一个人做对的事，不是为了得到回报，只是因为这是应该做的事。这样的行为积累多了，就会产生一种强大的精神力量，这就是浩然之气。

4.3 告子的挑战：气和仁义之间的关系

告子曾经挑战孟子：浩然之气和仁义是什么关系？气是不是比心更重要？

孟子回答：“志壹则动气，气壹则动志。“心志专一会推动气的流动，气专一也会反过来影响心志。这里的"壹"是专一的意思。心和气是互相影响的：如果你的志向坚定，你的精神状态就会积极；反过来，如果你养成了浩然之气，你的志向也会更加坚定。

但孟子同时强调：“夫志，气之帅也；气，体之充也。“心志是气的统帅，气是充满身体的力量。所以最重要的是"持其志，无暴其气”——保持心志的稳定，不要让自己的气胡乱发泄。这是一个双向的过程：既要培养气，也要涵养志，两者缺一不可。

五、《孟子》为何影响深远

5.1 民本思想：中国最早的"人权"观念

《孟子》最震撼人心的一句话是：“民为贵，社稷次之，君为轻。“百姓是最重要的，其次是国家，最不重要是国君。这不是说要推翻国君，而是说国君存在的意义是为百姓服务，如果国君不能履行这个职责，百姓有权推翻他。

孟子的民本思想，在当时是革命性的言论。即使在今天，它依然具有强大的现实意义：政府的合法性来源于为人民服务，而不是来源于血统或者武力。如果一个政府不能保障人民的基本福祉，它就失去了存在的正当性。这种思想，在中国历史上一次又一次地激励着人们反抗暴政，成为中国政治文化的宝贵遗产。

5.2 养气说：对士人心灵的塑造

孟子的"浩然之气"和"养心"学说，对中国士人的人格塑造产生了深远的影响。文天祥在《正气歌》中写道：“天地有正气，杂然赋流形。下则为河岳，上则为日星。“这种正气的观念，直接来源于孟子。

中国历史上的士人，面对政治黑暗和权力压迫，经常选择"独善其身"而不是"同流合污”。他们依靠的正是这种浩然之气——一种由内心正义积累而成的精神力量。陶渊明不为五斗米折腰，苏东坡流放黄州仍然乐观旷达，于谦"粉身碎骨浑不怕，留取丹心照汗青”——这些士人的精神风貌，都可以在孟子的"养气说"中找到根源。

5.3 现代启示：当我们谈"正能量"时，孟子早已说过

当代人喜欢谈"正能量”，孟子谈的"浩然之气"其实就是一种正能量的古典表达。两者的共同点是：都认为有一种积极正面的精神力量可以影响人的行为和命运。不同点是：孟子的浩然之气需要通过长期的正义行为来培养，不能一蹴而就；而当代的"正能量"有时被简化为一种心态的调整，似乎只要"想开了"就能获得。

孟子告诉我们：真正的精神力量来自实践，而不是空想。你必须在具体的事情上做正确的选择，日积月累，才能形成真正的浩然之气。这个道理，在今天依然有效——你不能通过每天喊口号获得精神力量，你只能通过每天做正确的事情来积累它。

结语

读《孟子》，最让人印象深刻的是他的"气势”——那种"说大人则藐之"的傲然，那种"当今之世，舍我其谁"的担当。他是儒家思想家中最有战斗性的一位，面对诸侯王的威势，他不卑不亢，敢于直接指出他们的错误。

但他的底气不是来自傲慢，而是来自他坚信的真理：人性本善，每个人都有成为君子的可能；仁政是治国平天下的唯一正道，任何偏离仁政的政治最终都会失败；浩然之气是由正义积累而成的精神力量，足以抵御任何外在的压力。

孟子说：“如欲平治天下，当今之世，舍我其谁也？“如果要治理天下，在当今这个时代，除了我还能有谁呢？这种自信，不是盲目的自大，而是建立在对人性的深刻理解和对真理的坚定信念之上的。两千多年过去了，孟子的声音依然在我们的耳边回响：当社会出现不公的时候，我们是否有勇气像他一样，大声地说出真理？
